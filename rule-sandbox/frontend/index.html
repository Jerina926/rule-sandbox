◈系统说明

本系统通过构建不同类型的虚拟社会，结合问卷数据、公开数据和行为推演模型，模拟规则发布后不同群体的反应变化。V2 版本内置场景识别引擎：系统会先识别你选择的虚拟社会类型，再解析发布内容属于的规则类别，识别五类影响主体（直接受影响 / 间接受影响 / 管理执行 / 潜在受损 / 高风险行为主体），然后生成贴合该场景的专属分析——不会出现学校场景里冒出补贴、医保等无关词语的串场情况。

当前模式

独立运行 · 本地规则库推演
